# L2 – Thiết kế Màn hình

## 1. Layout tổng thể

```
┌──────────────────────────────────────────────────────────┐
│  ☰  Header (toggle sidebar)                              │
├──────────┬───────────────────────────────────────────────┤
│ Sidebar  │  Breadcrumb: Home > Truyện Tranh              │
│          ├───────────────────────────────────────────────┤
│ 🏠 Home  │                                               │
│ 📚 Truyện│           <Page Content>                      │
│   Tranh  │                                               │
│          │                                               │
└──────────┴───────────────────────────────────────────────┘
```

---

## 2. Màn hình danh sách truyện (`/comics`)

```
┌─────────────────────────────────────────────────────────────┐
│  Quản lý Truyện Tranh              [ + Thêm mới ]           │
├─────────────────────────────────────────────────────────────┤
│  🔍 [Tìm tên truyện...     ] [Lọc trạng thái ▼] [Search]  │
├────┬───────┬─────────────┬──────────┬────────────┬──────────┬──────────────────┤
│ #  │ Ảnh  │ Tên truyện  │ Tác giả  │ Thể loại   │ TT       │ Số ch │ Thao tác │
├────┼───────┼─────────────┼──────────┼────────────┼──────────┼───────┼──────────┤
│ 1  │ [img] │ One Piece   │ Oda      │ Phiêu lưu  │[Đ.Phát]  │  110  │[Xem][Sửa][Xóa]│
│ 2  │ [img] │ Naruto      │ Kishimoto│ Hành động  │[H.Thành] │  700  │[Xem][Sửa][Xóa]│
├────┴───────┴─────────────┴──────────┴────────────┴──────────┴───────┴──────────┤
│  Trang 1/3    [ < ] [ 1 ] [ 2 ] [ 3 ] [ > ]                                   │
└────────────────────────────────────────────────────────────────────────────────┘
```

**Trạng thái Tag:**
- `ongoing` → Tag màu xanh dương: "Đang phát hành"
- `completed` → Tag màu xanh lá: "Hoàn thành"  
- `paused` → Tag màu cam: "Tạm dừng"
